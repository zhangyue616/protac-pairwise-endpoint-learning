# Aggregation source archive

This directory archives 15 original author scripts that contributed to 47 released companion tables. `PRODUCER_MAP.csv` records table row counts, statistical functions or source blocks, historical callers, and subsequent assembly/publication steps; multiple entries in a cell are separated by ` | `. `build_si_tables_r3.py` is a retained runtime-generated file. `extract_mapping.py` computes some component summaries, including means, counts, ties, and ranges; it is not solely a file copier.

The scripts have not been rerun for this archive. They depend on unpublished local run artifacts and cannot be executed directly from the public inputs alone. Retained records do not bind every script's own hash to its historical invocation and exit status. Machine roots and internal directory names have been mechanically neutralized; all other source bytes and computational logic are retained, including existing checks and historical source transformations.

Inputs fall into three groups. Public materials include opaque indices and frozen splits, component mappings, scientific configurations, label-free predictions, and released aggregates. Main-dataset scientific inputs can be reconstructed with the existing reconstruction code from TACK revision `0ebfb3627cfeee826c3392586d46940402237b11`, file `DC50/train-00000-of-00001.parquet`, subject to source access terms; these inputs do not recover every original run artifact. Unpublished dependencies include complete external-case structures and measurements, model caches, selection/runtime receipts, training logs, original contracts, and frozen historical tables.

The existing `downstream_adapter.py` dynamically extracts summary functions, changes dependency paths, and redirects administrative `FIT_COMPLETE` ledger reads to logical fit coverage; the statistical formulas are retained. This behavior predates this archive.

The historical halves of the four S29 `HISTORICAL_COMPARISON` tables depend on ten unpublished frozen tables. `corrected_minus_historical` includes the 5,788-to-5,804 pair population change and combined analysis changes, so it does not isolate a graph correction effect. For the ten scenario-filtered S29 tables, final assembly used default pandas parsing and rewriting, which changed some values by at most `2.22e-16` relative to the upstream aggregates. Repeating only this read, filter and write step in memory with pandas 3.0.3 reproduced the released bytes of all ten tables; no statistics were recalculated.
